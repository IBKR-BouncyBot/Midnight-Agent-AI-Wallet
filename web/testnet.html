01 / CONNECT

Connect Lace.
Prove in your browser.

Use Lace 2.5 or later with Midnight enabled and Preview selected. No Node runner, Docker or separate proof server is needed.

Open this page in the browser where Lace is installed.

In Lace’s Midnight settings, choose Run in this app (WASM) proving. Lace creates its wallet and fee proofs internally; this page creates the vault proofs in a background worker.

Lace does not expose this setting to websites. Keep it selected while using the demo. An external prover can read private proof inputs.

Use at least 16 characters. This encrypts this app’s vault state; it is separate from your Lace password. We never ask for your wallet seed.

Keep the password and an encrypted backup. Clearing browser storage removes this device’s vault state; your Lace seed cannot recreate it. Proof keys download on first use. Proving speed and memory requirements depend on your device.
