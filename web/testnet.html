01 / CONNECT

Pair with your local runner.

The runner creates and stores disposable demo keys on your device, and uses public Preview services. This website never asks for a wallet seed.

  1. Start the runner from the repository.
    node services/demo/server.mjs

    Follow the repository setup guide first. Use the printed localhost link to open this page with a temporary pairing token.

  2. Keep the local proof server running.

    The runner needs the supported Midnight proof server. Private proof inputs must stay on your device.

  3. Connect, then fund the fresh test wallet.

    The next screen shows the generated funding address and official Preview faucet. Use test assets only.

Usually filled by the launcher link. Kept only in this tab's memory, never in browser storage.
